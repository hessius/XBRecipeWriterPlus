## Background the engineer needs

`library/brew/handoff/handoffBean.ts` maps a `PodCoffee` (our vocabulary) onto a
`HandoffBean` (Beanconqueror's). It is spread-based: each optional field is
contributed by a helper that returns either `{}` or `{key: value}`, so a field
with nothing to say is absent from the JSON rather than present and empty.

Three facts constrain the fix:

1. **`decaffeinated: false` must survive.** `false` is an answer, not absence.
   Any presence check that treats falsy as absent breaks it. There is already a
   test named "keeps a decaffeinated coffee's answer, including no".
2. **`elevation: 0` must survive**, stringified as `"0"`. It is converted to a
   string before reaching the helper, and `"0"` is not blank, so a blank check
   on strings leaves it alone. There is a test for this too.
3. **`origin ?? country` uses `??`**, which only falls through on `null` and
   `undefined`. An empty-string origin therefore wins over a real country. This
   is the actual bug the reviewer found.

The four findings:

- Two mediums, both on the same helper, both the blank-string issue (Task 2).
- One low asking for a clearer helper name (Task 1).
- One low, a grammar fix in a spec document (Task 3).

## Task 1: Rename the helper to say what it does

The reviewer's complaint is that `said` does not tell a skimming reader that the
function conditionally includes a property. They suggested `optionalField`,
`whenDefined` or `definedProp`.

Use **`whenSaid`**. It fixes exactly what they objected to (the conditional is
now in the name) while keeping the file's "saying" metaphor, which its doc
comment and its tests are both built on: the existing test is called *"says
nothing rather than something empty"*. `whenDefined` would also become a lie in
Task 2, when the helper starts omitting defined-but-blank values.

This task is a pure rename. Behaviour does not change and no test changes.

**Files:**
- Modify: `library/brew/handoff/handoffBean.ts`

- [ ] **Step 1: Rename the function and its three call-site groups**

In `library/brew/handoff/handoffBean.ts`, change the declaration from:

```ts
/** Present only when there is something to say. */

    key: K,
    value: T | undefined

    return value === undefined ? {} : ({[key]: value} as Partial<Record<K, T>>);
```

```ts
export function handoffBean(coffee: PodCoffee): HandoffBean {

        name: coffee.name,
```

- [ ] **Step 3: Write the implementation**

In `library/brew/handoff/handoffBean.ts`, replace the `whenSaid` declaration
from Task 1 with this pair of helpers:

```ts
/**
 * Contributes the key only when there is something to say.
 *
 * A blank string is nothing said. The endpoints behind `PodCoffee` answer an
 * unknown field with an empty string about as often as they omit it, and a
 * field that arrives empty looks to the receiving app like a field somebody
 * filled in with nothing, which is a worse claim than silence.
 *
 * The check is on strings alone, deliberately. `decaffeinated: false` is an
 * answer and must survive, and an elevation of zero reaches here as the string
 * `"0"`, which is not blank.
 */
function whenSaid<K extends string, T>(
    key: K,
    value: T | undefined
): Partial<Record<K, T>> {
    if (value === undefined) return {};
    if (typeof value === "string" && value.trim() === "") return {};
    return {[key]: value} as Partial<Record<K, T>>;
}

/** The first of these that says anything, if any of them do. */
function firstSaid(
    ...values: (string | undefined)[]
): string | undefined {
    return values.find(
        value => value !== undefined && value.trim() !== ""
    );
}
```

Then change the origin line in `handoffBean` from:

```ts
        ...whenSaid("origin", coffee.origin ?? coffee.country),
```

to:

```ts
        ...whenSaid("origin", firstSaid(coffee.origin, coffee.country)),
```

Note what is **not** changed: a non-blank value is contributed exactly as it
arrived, untrimmed. Trimming `" Kenya "` to `"Kenya"` would be an improvement
but it is a different change from the one review asked for, and this branch is a
review close-out.
